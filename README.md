# GitHub Awesome 系列导航

这是一份按主题整理的 GitHub Awesome 清单导航。Awesome 项目通常由社区持续维护，用来汇总某个领域中值得关注的库、工具、教程、论文和实践资料。

> 本文是精选入口，不追求穷尽。仓库的 Star 数和更新时间变化很快，因此不在文档中记录这些数据。最后核对：2026-08-11。

## 总入口

| 名称 | 内容 |
| --- | --- |
| [sindresorhus/awesome](https://github.com/sindresorhus/awesome) | 最主要的 Awesome 总索引，覆盖开发、科学、平台、媒体、学习等大量主题。 |
| [The Ultimate Awesome List](https://github.com/andrew/ultimate-awesome) | 自动生成并定期更新的大型 Awesome 清单索引。 |
| [GitHub Awesome Topics](https://github.com/topics/awesome) | GitHub 官方的 `awesome` 主题页，适合发现热门或最近更新的清单。 |
| [GitHub Awesome List Topics](https://github.com/topics/awesome-list) | 使用 `awesome-list` 标签的仓库集合，可按语言和热度筛选。 |

## 如何继续发现

1. 先从 [sindresorhus/awesome](https://github.com/sindresorhus/awesome) 的分类目录查找主题。
2. 在 GitHub 搜索 `awesome + 关键词`，再结合 `awesome-list` Topic 筛选。
3. 检查仓库最近提交、Issue 和 Pull Request，确认清单仍在维护。
4. 比较同一主题下的多个清单；优先选择分类清晰、链接检查自动化、贡献规范完整的项目。

## 收录建议

新增条目时建议满足以下条件：

- 内容是经过筛选的主题清单，而不是未经整理的链接堆积。
- 仓库公开可访问，说明清晰，链接仍然有效。
- 优先收录持续维护、社区参与活跃、具有明确贡献规范的项目。
- 使用 `名称 + GitHub 链接 + 一句话说明` 的格式，并放入最贴近的分类。
